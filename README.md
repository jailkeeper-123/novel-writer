# 소설 쓰기

폰에서 소설을 편하게 쓰기 위한 웹 에디터입니다. 파일 하나(`index.html`)로 동작하고, 서버나 설치가 필요 없습니다.

## 기능

- 따옴표와 괄호 자동 완성: `"`를 한 번 누르면 `""`가 입력되고 커서가 가운데에 놓입니다. `'`, `( )`, `[ ]`, `{ }`, `“ ”`, `‘ ’`, `「 」`, `『 』`, `《 》`, `〈 〉`도 같습니다.
- 엔터로 대사 완료: 닫는 따옴표 앞에서 엔터를 누르면 따옴표 밖으로 나갑니다.
- 서식: 글꼴, 글자 크기, 줄 간격, 문단 간격(엔터로 나눈 문단 사이), 글자 간격, 좌우·상하 여백, 들여쓰기(1칸/2칸, 대사 줄 제외), 배경색(프리셋 + 색상환)
- 페이지 모양: 자유 / 3:4 쪽 / 5:5 쪽. 쪽이 바뀌는 자리에 점선과 쪽 번호를 표시하고, 새 쪽의 위 여백도 1쪽과 같게 보여 줌
- 내 글꼴 추가: ttf, otf, woff, woff2 파일을 여러 개 한 번에 추가
- 임시저장: 글 목록 보관, 불러오기, 삭제
- 이미지로 저장: PNG, JPG (페이지 크기에 맞춰 여러 장으로 나눔)
- 글자 수 표시(공백 제외, 누르면 공백 포함)

## 데이터 저장

모든 글, 임시저장, 설정, 추가한 글꼴은 사용 중인 기기의 브라우저(localStorage, IndexedDB)에만 저장됩니다. 서버로 전송되지 않으며, 기기 간 자동 동기화도 없습니다. 기기를 옮길 때는 "전체 복사" 버튼으로 글을 복사해 옮기세요.

## 사용 방법

GitHub Pages로 배포한 주소를 폰 브라우저에서 열고, 브라우저 메뉴의 "홈 화면에 추가"를 하면 앱처럼 쓸 수 있습니다.

## 배포 (GitHub Pages)

1. 이 저장소에 `index.html`을 올립니다.
2. Settings → Pages → Build and deployment에서 Source를 "Deploy from a branch", Branch를 `main` / `(root)`로 정하고 Save합니다.
3. 잠시 뒤 `https://<사용자명>.github.io/<저장소명>/` 주소로 열립니다.

## 참고

- 기본 글꼴 "Noto Serif KR"은 Google Fonts에서 불러옵니다. 오프라인에서는 시스템 명조 글꼴로 대체됩니다.
- 이미지 저장은 캔버스 기능을 쓰며, 글자 모양이 화면과 조금 다를 수 있습니다.
